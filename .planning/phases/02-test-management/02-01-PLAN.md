  <action>
Create API client layer that wraps fetch calls to the FastAPI backend.

In `frontend/src/api/client.js`:
- Base URL: Use Vite proxy, so just `/api`
- Create helper functions:
  - `apiGet(path)` - GET request, returns JSON
  - `apiPost(path, body)` - POST with JSON body, returns JSON
  - `apiPut(path, body)` - PUT with JSON body, returns JSON
  - `apiDelete(path)` - DELETE request, returns nothing
  - `apiUpload(path, file)` - POST with FormData for file upload, returns JSON
- Handle errors: throw Error with response status and message

In `frontend/src/api/testCases.js`:
```javascript
export async function createTestCase(name, lineup, imageHash = null)
export async function getTestCases()
export async function getTestCase(id)
export async function updateTestCase(id, updates)
export async function deleteTestCase(id)
```
Map to backend endpoints: POST/GET/PUT/DELETE /api/test-cases

In `frontend/src/api/images.js`:
```javascript
export async function uploadImage(file) // Returns { hash }
export function getImageUrl(hash) // Returns URL string for img src
```
Map to: POST /api/images, GET /api/images/{hash}

The getImageUrl function should just return the URL string, not fetch it (for use in img src).
