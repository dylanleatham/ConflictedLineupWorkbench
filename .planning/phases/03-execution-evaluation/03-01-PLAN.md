  <action>
Create `backend/services/` directory with `__init__.py` and `evaluator.py`.

In `evaluator.py`, implement `calculate_accuracy(extracted: List[str], ground_truth: List[str]) -> dict` that:
1. Normalizes strings: strip whitespace, lowercase for comparison
2. Uses set operations for efficient matching
3. Returns dict with:
   - `total_ground_truth`: count of ground truth artists
   - `total_extracted`: count of extracted artists
   - `matched`: count of matches
   - `accuracy_percentage`: float (0-100), rounded to 2 decimals
   - `missed`: list of artists in ground truth but not extracted (original casing)
   - `extra`: list of artists extracted but not in ground truth
   - `matched_artists`: list of matched artists (original casing from ground truth)

Handle edge cases:
- Empty ground truth: return 0% accuracy
- Empty extracted: return 0% accuracy with all ground truth as missed
- Duplicates: use sets (duplicates don't double-count)

In `__init__.py`, export `calculate_accuracy`.
  </action>

First, add `anthropic>=0.40.0` to `backend/requirements.txt`.

In `backend/services/claude.py`, implement:

1. `parse_claude_json_response(response_text: str) -> List[str]`:
   - Try direct JSON parse first
   - Try extracting from markdown code fence (```json ... ```)
   - Try finding array pattern as fallback
   - Raise ValueError if unparseable

2. `async def extract_lineup_from_text(festival_name: str, system_prompt: str, model: str, timeout: float = 60.0) -> List[str]`:
   - Uses AsyncAnthropic client
   - API key from os.environ.get("ANTHROPIC_API_KEY")
   - Wraps with asyncio.wait_for for timeout
   - Message: system_prompt + "\n\nFestival: " + festival_name
   - Returns parsed lineup

3. `async def extract_lineup_from_image(image_path: Path, system_prompt: str, model: str, timeout: float = 60.0) -> List[str]`:
   - Read image, base64 encode
   - Detect media type using Pillow (already installed)
   - Validate format is jpeg/png/gif/webp
   - Send as vision message with image + system_prompt text
   - Returns parsed lineup

Error handling:
- asyncio.TimeoutError: re-raise with descriptive message
- RateLimitError: let it bubble up (SDK handles retries)
- Other exceptions: wrap with context

Update `__init__.py` to export `extract_lineup_from_text`, `extract_lineup_from_image`.
