Create `backend/api/executions.py` with FastAPI router.

Define Pydantic models:
```python
class ExecutionRequest(BaseModel):
    system_prompt: str
    model: str

class AccuracyResult(BaseModel):
    total_ground_truth: int
    total_extracted: int
    matched: int
    accuracy_percentage: float
    missed: List[str]
    extra: List[str]
    matched_artists: List[str]

class ExecutionResult(BaseModel):
    test_id: str
    status: str  # "success" or "failed"
    extracted_lineup: Optional[List[str]] = None
    accuracy: Optional[AccuracyResult] = None
    error: Optional[str] = None
    metadata: dict  # model, system_prompt, timestamp
```

Implement `POST /api/executions/{test_id}/{mode}` where mode is "text" or "image":
1. Load test case by ID (404 if not found)
2. For image mode: validate test case has image_hash (400 if missing)
3. Call appropriate Claude service function
4. Calculate accuracy against ground truth
5. Return ExecutionResult with success status

Error handling:
- Timeout: return 504 with timeout message
- Other errors: return 500 with error message in result

Import from services:

  <action>
In `executions.py`, add batch execution infrastructure:

1. In-memory batch state storage:
```python
from dataclasses import dataclass, field
from typing import Dict

@dataclass
class BatchState:
    total: int
    completed: int = 0
    failed: int = 0
    cancelled: bool = False
    current_test_id: Optional[str] = None
    results: List[ExecutionResult] = field(default_factory=list)

batch_states: Dict[str, BatchState] = {}
```

2. Define batch models:
```python
class BatchRequest(BaseModel):
    test_ids: List[str]
    mode: str  # "text" or "image"
    system_prompt: str
    model: str

class BatchSummary(BaseModel):
    total: int
    completed: int
    failed: int
    perfect_count: int  # 100% accuracy
    average_accuracy: float
    results: List[ExecutionResult]
```

3. `POST /api/executions/batch` endpoint:
   - Generate batch_id using uuid or timestamp
   - Initialize BatchState
   - Use FastAPI BackgroundTasks to run batch in background
   - Return {"batch_id": str, "status": "started"}

4. Background batch executor function:
   - Loop through test_ids
   - Check cancelled flag before each test
   - Execute single test with try/except (continue on failure)
   - Update BatchState after each test
   - Mark failed tests with error message

5. `GET /api/executions/batch/{batch_id}/progress` endpoint:
   - Return current BatchState as JSON
   - 404 if batch not found

6. `POST /api/executions/batch/{batch_id}/cancel` endpoint:
   - Set cancelled=True on BatchState
   - Return current state

7. `GET /api/executions/batch/{batch_id}/results` endpoint:
   - Return BatchSummary with all results
   - Calculate perfect_count and average_accuracy

In `backend/main.py`, add: `app.include_router(executions.router)`
