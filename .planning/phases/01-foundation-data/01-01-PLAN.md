<task type="auto">
  <name>Task 2: Create Pydantic model for test cases</name>
  <files>backend/storage/models.py</files>
  <action>
    Create `backend/storage/models.py` with TestCase Pydantic model:

    ```python
    from pydantic import BaseModel, Field
    from typing import List, Optional

    class TestCase(BaseModel):
        """Model for a festival test case."""
        id: str = Field(..., description="Unique identifier for the test case")
        name: str = Field(..., description="Festival name (e.g., 'Coachella 2024')")
        image_hash: Optional[str] = Field(None, description="SHA-256 hash of stored image, None if no image")
        lineup: List[str] = Field(default_factory=list, description="Ground truth list of artist names")

        model_config = {
            "json_schema_extra": {
                "example": {
                    "id": "001-coachella-2024",
                    "name": "Coachella 2024",
                    "image_hash": "a1b2c3d4e5f6...",
                    "lineup": ["The Weeknd", "Daft Punk", "Billie Eilish"]
                }
            }
        }
    ```

    Key points:
    - id is required (will be generated on creation)
    - image_hash is optional (test case can exist without image initially)
    - lineup defaults to empty list
    - Use Pydantic v2 model_config instead of Config class
  </action>
  <verify>
    Run: python -c "from backend.storage.models import TestCase; tc = TestCase(id='001', name='Test Festival'); print(tc.model_dump_json())"
    Expected: Prints JSON with id, name, image_hash=None, lineup=[]
  </verify>
  <done>

       - Delete DATA_DIR / f"{test_case_id}.json"
       - Return True if deleted, False if didn't exist
       - Do NOT delete associated image (may be shared)

    Implementation notes from RESEARCH.md:
