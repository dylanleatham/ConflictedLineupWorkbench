<task type="auto">
  <name>Task 1: Implement image storage with optimization and deduplication</name>
  <files>backend/storage/images.py</files>
  <action>
    Create `backend/storage/images.py` with image handling:

    1. Constants:
       - MAX_IMAGE_SIZE = 10 * 1024 * 1024 (10MB)
       - MAX_WIDTH = 1200 (resize larger images)
       - JPEG_QUALITY = 85

    2. `optimize_image(image_bytes: bytes) -> bytes`:
       - Open with Pillow
       - Convert RGBA/LA/P to RGB (JPEG compatibility)
       - Resize if width > MAX_WIDTH (maintain aspect ratio, use LANCZOS)
       - Save as JPEG with quality=85, optimize=True
       - Return optimized bytes

    3. `save_image(image_bytes: bytes) -> str`:
       - Optimize the image first
       - Generate SHA-256 hash of OPTIMIZED bytes (not original)
       - Save to IMAGES_DIR / f"{hash}.jpg"
       - Skip write if file exists (deduplication)
       - Return the hash

    4. `get_image_path(image_hash: str) -> Optional[Path]`:
       - Return IMAGES_DIR / f"{image_hash}.jpg" if exists
       - Return None if not found

    5. `image_exists(image_hash: str) -> bool`:
       - Check if IMAGES_DIR / f"{image_hash}.jpg" exists

    Implementation notes from RESEARCH.md:
    - Use hashlib.sha256() for content hashing
    - Pillow Image.verify() then reopen for processing
    - Create IMAGES_DIR on first save if needed
  </action>
  <verify>
    Run test script with a sample image:
    ```python
    from backend.storage.images import save_image, get_image_path, image_exists
    from pathlib import Path

    # Create a simple test image (red 100x100 square)
    from PIL import Image
    from io import BytesIO
    img = Image.new('RGB', (100, 100), color='red')
    buffer = BytesIO()
    img.save(buffer, format='PNG')
    test_bytes = buffer.getvalue()

    # Save it
    hash1 = save_image(test_bytes)
    print(f"Saved with hash: {hash1}")

    # Check exists
    assert image_exists(hash1)
    assert get_image_path(hash1).exists()

    # Save again - should get same hash (deduplication)
    hash2 = save_image(test_bytes)
    assert hash1 == hash2

    print("Image storage tests passed!")
    ```
  </verify>
  <done>
    - Images are optimized (resized if >1200px, compressed to JPEG)
    - Images are stored with SHA-256 hash as filename
    - Duplicate images return same hash without writing again
    - get_image_path returns valid Path for existing images
  </done>
